# ADR-0003: Frontend με Thymeleaf

- **Κατάσταση:** Αποδεκτή
- **Ημερομηνία:** 2026-11-26
- **Σχετικά:** #24 (TS-04), [αρχιτεκτονική, §5](../architecture.md#5-frontend)

## Πλαίσιο

Η Ενότητα 5 της εκφώνησης ορίζει Java για το backend και αφήνει την τεχνολογία του απλού web frontend στην ομάδα, σε συνεννόηση με τον διδάσκοντα. Η αξιολόγηση εστιάζει στη μηχανική λογισμικού και όχι στην πολυπλοκότητα του UI. Η ομάδα έχει 6 μέλη και όλα γράφουν Java. Το UI πρέπει να είναι έτοιμο για επίδειξη σε κάθε Sprint Review.

## Απόφαση

Οι σελίδες δημιουργούνται στον server με **Thymeleaf**, μέσα στην ίδια εφαρμογή Spring Boot:

- **Σελίδες:** `@Controller` στο package `web` κάθε module, με templates στο `templates/<module>/`.
- **Layout:** κοινό layout με fragments στο `templates/fragments/layout.html` (`head`, `header`, `messages`, `footer`).
- **Στατικά αρχεία:** CSS και JS στο `static/`, χωρίς frontend build και χωρίς εξωτερικές βιβλιοθήκες.
- **REST API:** δίπλα στις σελίδες υπάρχει REST API (`@RestController`, `/api/**`) για τους αυτοματοποιημένους ελέγχους και το OpenAPI. Οι δύο controllers κάθε ενέργειας καλούν το ίδιο service.
- **Σφάλματα:** το REST API επιστρέφει `ProblemDetail`, ενώ οι σελίδες δείχνουν μήνυμα στη φόρμα ή τη σελίδα σφάλματος του `templates/error/`.
- **Τρέχων παίκτης:** αναγνωρίζεται από το ίδιο cookie στις σελίδες και στο API. Χωρίς παίκτη, οι σελίδες ανακατευθύνουν στο `/player` και το API απαντά 401.

## Συνέπειες

**Θετικές**

- Ένα project, ένα build, ένα Docker image.
- Όλη η ομάδα δουλεύει σε Java. Δεν χρειάζεται δεύτερο toolchain (Node, npm).
- Οι σελίδες ελέγχονται με `@WebMvcTest` και `MockMvcTester`, χωρίς browser.
- Δεν υπάρχουν CORS ή tokens στο JavaScript: το cookie είναι `HttpOnly`.

**Αρνητικές**

- Το UI είναι λιγότερο διαδραστικό: κάθε ενέργεια ανανεώνει τη σελίδα. Αν χρειαστεί, προστίθεται htmx σε συγκεκριμένα σημεία χωρίς αλλαγή αρχιτεκτονικής.
- Κάθε ενέργεια έχει δύο controllers, έναν για τη σελίδα και έναν για το API.

## Εναλλακτικές που εξετάστηκαν

| Εναλλακτική | Γιατί δεν επιλέχθηκε |
|-------------|----------------------|
| SPA (π.χ. React + Vite) | Δεύτερο build και toolchain, CORS και tokens, περισσότεροι έλεγχοι. Χρόνος που θα έλειπε από τη μηχανική λογισμικού. |
| Thymeleaf + htmx από την αρχή | Δεν χρειάζεται ακόμη. Μπορεί να προστεθεί αργότερα σε όποια σελίδα χρειάζεται. |
