# AI-usage log

Καταγραφή των σημαντικών χρήσεων εργαλείων AI στο έργο (Ενότητα 4.4 της εκφώνησης). Δεν καταγράφουμε κάθε προτροπή. Καταγράφουμε τις περιπτώσεις που επηρέασαν τον κώδικα, τους ελέγχους, τον σχεδιασμό ή την τεκμηρίωση.

## Κανόνες

- Το log ενημερώνεται **σε κάθε sprint**, όχι μόνο στο τέλος.
- Σε κάθε sprint καταγράφεται **τουλάχιστον μία** περίπτωση όπου η πρόταση του εργαλείου ήταν λανθασμένη, ελλιπής ή επικίνδυνη, μαζί με τον τρόπο που εντοπίστηκε.
- Η έγκριση για merge δίνεται πάντα από μέλος της ομάδας. Ένα εργαλείο AI μπορεί να είναι μόνο πρόσθετος reviewer.
- Κωδικοί, κλειδιά API και προσωπικά δεδομένα δεν μπαίνουν ποτέ σε προτροπές.
- Η ευθύνη για την ορθότητα και την ασφάλεια ανήκει στην ομάδα, όποιος κι αν έγραψε τον κώδικα.

## Μορφή καταχώρισης

| Πεδίο | Περιεχόμενο |
|-------|-------------|
| Ημερομηνία | ΕΕΕΕ-ΜΜ-ΗΗ |
| Μέλος | Ποιος χρησιμοποίησε το εργαλείο |
| Εργαλείο | Όνομα και, αν είναι γνωστό, μοντέλο |
| Σκοπός | Απαιτήσεις, σχεδίαση, κώδικας, έλεγχοι, debugging, review, τεκμηρίωση |
| Τι πρότεινε | Σύντομη περιγραφή |
| Απόφαση | Αποδεκτό / Αποδεκτό με αλλαγές / Απορρίφθηκε, και γιατί |
| Επαλήθευση | Πώς ελέγξαμε το αποτέλεσμα |
| Σύνδεσμοι | Issue, PR, commit |
