# Definition of Done

Μια story ή τεχνική εργασία θεωρείται ολοκληρωμένη μόνο όταν ισχύουν **όλα** τα παρακάτω. Η ομάδα αναθεωρεί τη λίστα στα retrospectives. Κάθε αλλαγή καταγράφεται στο ιστορικό στο τέλος του αρχείου.

## 1. Για κάθε user story ή τεχνική εργασία

### Ελάχιστα κριτήρια (Ενότητα 4.1 της εκφώνησης)

- [ ] Τα acceptance criteria καλύπτονται από αυτοματοποιημένους ελέγχους που περνούν.
- [ ] Ο κώδικας ενσωματώθηκε στο `main` μέσω pull request, με έγκριση από τουλάχιστον ένα άλλο μέλος.
- [ ] Το CI είναι επιτυχές: μεταγλώττιση, όλοι οι έλεγχοι και στατική ανάλυση.
- [ ] Ενημερώθηκε η σχετική τεκμηρίωση (README, OpenAPI, CHANGELOG) όπου χρειάζεται.

### Επιπλέον κριτήρια της ομάδας

- [ ] Το PR συνδέεται με το issue της story (`Closes #N`). Το issue έχει owner, εκτίμηση και milestone.
- [ ] Η στατική ανάλυση δεν βγάζει νέες παραβιάσεις. Κάθε εξαίρεση (suppression) συνοδεύεται από σχόλιο που την αιτιολογεί.
- [ ] Οι έλεγχοι δεν καλούν ζωντανά δημόσια APIs. Χρησιμοποιούν mocks, stubs ή fixtures.
- [ ] Οι κανόνες της αποστολής (ποιος γρίφος είναι ανοιχτός, ποιο στοιχείο έχει αποκαλυφθεί) ελέγχονται στο backend. Το backend δεν εμπιστεύεται ό,τι στέλνει ο client.
- [ ] Αν άλλαξε το module κανόνων της αποστολής, εκτελέστηκε το PIT και εξετάστηκαν οι mutants που επέζησαν.
- [ ] Το πεδίο «Χρήση εργαλείων AI» του PR είναι συμπληρωμένο. Οι σημαντικές χρήσεις καταγράφονται στο [AI-usage log](ai-usage-log.md).
- [ ] Δεν υπάρχουν κωδικοί, κλειδιά API ή προσωπικά δεδομένα στον κώδικα, στα fixtures ή στα logs.
- [ ] Η λειτουργία δοκιμάστηκε στην εφαρμογή που τρέχει, τοπικά ή με Docker, και όχι μόνο μέσα από τους ελέγχους.
- [ ] Ο owner και ο reviewer μπορούν να εξηγήσουν την υλοποίηση αν τους ζητηθεί.
- [ ] Τα «Αποδεικτικά ολοκλήρωσης» του issue είναι συμπληρωμένα (PR, έλεγχοι, έκδοση).

## 2. Για κάθε sprint

Ένα sprint κλείνει όταν, πριν από το Sprint Review:

- [ ] Όλες οι ολοκληρωμένες stories είναι στο `main` και το `main` είναι εκτελέσιμο.
- [ ] Ενημερώθηκε το [CHANGELOG](../CHANGELOG.md) και δημιουργήθηκε tag `vX.Y.Z` με GitHub release και σημειώσεις έκδοσης.
- [ ] Το pipeline δημοσίευσε Docker image με το ίδιο tag, και η έκδοση τρέχει με `docker compose` μόνο με αναφορά στο image.
- [ ] Η έκδοση και το commit εμφανίζονται στο `/actuator/info`.
- [ ] Το AI-usage log ενημερώθηκε για το sprint, με τουλάχιστον μία περίπτωση όπου η πρόταση του εργαλείου ήταν λανθασμένη, ελλιπής ή επικίνδυνη.
- [ ] Υπάρχει αναφορά PIT για το module κανόνων, από τη στιγμή που υπάρχει το module.
- [ ] Το product backlog είναι ενημερωμένο και τα αποτελέσματα του retrospective καταγράφηκαν στο αρχείο του sprint (`docs/sprints/`).
- [ ] Όλα τα μέλη υπέβαλαν peer assessment.

## Definition of Ready

Μια story μπαίνει σε sprint μόνο όταν:

- έχει σαφή διατύπωση «Ως / θέλω / ώστε»,
- έχει ελέγξιμα acceptance criteria,
- έχει εκτίμηση σε story points και χωράει σε ένα sprint,
- έχει owner,
- οι εξαρτήσεις της είναι γνωστές.
